# Editor toolbar icons

These PNGs are placeholders copied from the existing NifSkope artwork. Replace
individual files here with your own PNGs using the same filenames, then rebuild.
The resource aliases are in `res/nifskope.qrc` under `/edit`.

- `object`, `vertex`, `face`: active selection mode.
- `select`, `move`, `rotate`, `scale`: active transform tool.
- `mesh-tools`: Delete Selection / Snap Vertices / Mesh Center Pivot / X-Ray.
- `delete`, `snap`, `pivot`, `xray`: entries in the mesh tools dropdown.
- `materials`, `new-material`, `unique-material`: material dropdown and entries.
- `uv-editor`, `rebuild-collision`: independent toolbar buttons.

Square PNGs with transparency work best. The toolbar uses 18 or 36 pixel icons;
36x36 or larger source images support both sizes.
